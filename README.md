# 自动打卡系统

这是一个基于图像识别的自动打卡系统，可以帮助你实现自动登录和打卡操作。系统集成了 Telegram 机器人控制功能，让你可以随时远程操作和监控打卡状态。

## 功能特点

- 自动登录系统
- 定时上下班打卡
- 基于图像识别的界面操作
- Telegram 机器人远程控制
- 异常处理和日志记录
- 断网自动重连
- 系统运行监控
- 打卡记录管理
- 任务自动调度

## 环境要求

- Python 3.8+
- Tesseract OCR
- Chrome/Firefox 浏览器
- Telegram 机器人 Token

## 安装步骤

1. 安装 Tesseract OCR

   - 从[官方网站](https://github.com/UB-Mannheim/tesseract/wiki)下载并安装
   - 确保将安装路径添加到系统环境变量

2. 安装 Python 依赖

   ```bash
   pip install -r requirements.txt
   ```

3. 配置环境变量

   - 复制 `.env.example` 文件并重命名为 `.env`
   - 修改 `.env` 文件中的配置信息，包括：
     - 登录信息（用户名、密码、登录 URL）
     - Telegram 机器人 Token 和聊天 ID
     - Tesseract OCR 路径
     - 打卡时间配置

4. 准备模板图片
   - 在 `templates` 目录下添加以下截图：
     - username_field.png (用户名输入框)
     - password_field.png (密码输入框)
     - login_button.png (登录按钮)
     - punch_button.png (打卡按钮)

## 使用方法

1. 启动看门狗程序（推荐）

   ```bash
   python watchdog.py
   ```

   看门狗程序会自动启动主程序并监控其运行状态。如果主程序崩溃，看门狗会自动重启它。

2. 或者直接运行主程序

   ```bash
   python main.py
   ```

3. 程序会在工作日的以下时间自动执行打卡：

   - 上班打卡：09:00（可在.env 文件中自定义）
   - 下班打卡：17:30（可在.env 文件中自定义）

4. 使用 Telegram 机器人控制系统
   - `/start` - 获取使用帮助
   - `/status` - 查看当前系统状态
   - `/punch_in` - 手动执行上班打卡
   - `/punch_out` - 手动执行下班打卡
   - `/log` - 获取最近的日志信息
   - `/records` - 查看打卡记录
   - `/restart` - 重启系统
   - `/tasks` - 查看计划任务

## 系统组件

1. **主程序 (main.py)** - 包含自动打卡和 Telegram 机器人的核心功能

2. **看门狗程序 (watchdog.py)** - 监控主程序运行状态，在崩溃时自动重启

3. **任务管理器 (tasks.py)** - 管理计划任务和自动重试功能

4. **打卡记录管理 (punch_records.py)** - 记录和管理打卡历史

## 注意事项

1. 确保电脑在打卡时间段保持开机状态
2. 不要遮挡或最小化打卡系统界面
3. 建议先手动测试确保配置正确
4. 定期检查日志确保系统正常运行
5. 设置良好的网络环境，虽然系统具备断网重连能力

## 故障排除

1. 如果出现识别失败，请检查：

   - 模板图片是否清晰
   - 屏幕分辨率是否发生变化
   - 网络连接是否正常

2. 如果打卡失败，请检查：

   - 环境变量配置是否正确
   - 系统登录信息是否有效
   - Tesseract OCR 是否正确安装

3. 如果 Telegram 机器人无响应：

   - 检查 Token 是否正确
   - 确认网络连接是否正常
   - 查看日志中是否有连接错误

4. 系统资源占用过高：
   - 检查日志是否有异常错误循环
   - 重启系统
   - 检查是否有其他程序干扰
